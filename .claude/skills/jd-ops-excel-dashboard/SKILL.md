# 京东运营本地 Excel 看板

只依赖本 `SKILL.md`。读取**当前工作目录**（或用户指定目录）内全部 `.xlsx` / `.xls` / `.csv`，生成一份本地 Excel。

## 输出 6 张表

| 表名 | 数据 | 图 |
|------|------|----|
| 整体业绩 | 渠道、全渠道GMV | 柱形图：X=渠道，Y=金额 |
| 渠道贡献 | 渠道、销售额、占比%、排名 | 饼图：销售额占比 |
| 环比同比 | 日/周/月/年：本期、对比期、涨跌% | 双色柱 + 折线（涨跌%） |
| 达成率 | 月度/年度：实际、目标、完成率% | 叠加柱：目标空心、实际实心；完成率写在列/标签 |
| 费比 | ROI 实际/目标、花费、成交、费比% | 叠加柱：ROI 目标空心、实际实心；标费比数字 |
| 计划费用使用进度 | 计划名、已花费、月预算、当前使用率%、全月进度%、剩余、状态 | **仅表格** |

输出默认：`工作目录/京东运营看板.xlsx`。

## 源文件怎么读

跳过 `~$*`、文件名含「运营看板」的文件。CSV 编码依次试 `utf-8-sig` / `gbk` / `gb18030`。

| 文件名含 | 用途 | 关键列 |
|----------|------|--------|
| 流量来源 | 整体业绩、渠道贡献 | `一级渠道` + `引入成交金额`（不要用带「对比日/较对比日」的列） |
| 交易概况 | 环比同比、店铺GMV | `成交金额`、`成交金额-对比日`、`时间` |
| 流量概况 / 商品概况 | 成交金额补充 | `成交金额` |
| 推广 / 计划 / 报表中心 / 全站营销 | 费比、计划进度 | `花费`；成交优先 `全站交易额`/`总订单金额`；计划名 `商品计划名称`/`推广计划`；`日预算` |

未识别文件记入清单，不中断。渠道按 `一级渠道` 汇总金额后排序。

目标/预算：若目录有 `targets.yaml` 则读取；否则达成率/费比目标可向用户要，或先占位并标明「待补目标」。字段示例：`gmv_target_month`、`gmv_target_year`、`roi_target`、`fee_ratio_target`、`plans: [{name, month_budget, spent}]`。

## 怎么生成 Excel

优先用本机 **Python3 + openpyxl**（`pip install openpyxl`）。无 Python 时改用千问办公已有写 xlsx/出图能力，规则不变。

流程：

1. 确认输入目录，列出全部数据文件  
2. 按上表读入并汇总  
3. 写 6 张工作表 + 图表（样式见下）  
4. 保存后回报：路径、用了哪些文件、哪张表缺数据  

### 图表规则

- **整体业绩**：簇状柱，分类=渠道，值=GMV  
- **渠道贡献**：饼图，值=销售额，显示百分比；表内保留占比与排名  
- **环比同比**：本期/对比期两柱不同色；折线=涨跌%（次坐标轴）  
- **达成率 / 费比**：实际实心、目标无填充+描边（空心）；完成率% / 费比% 写在数据列  
- **计划费用使用进度**：列=计划名称｜已花费｜月预算｜当前使用率%｜全月使用进度%｜剩余预算｜状态（正常/预警≥80%/超支≥100%）；全月进度≈当月已过天数/当月天数  

### 计算要点

- 占比 = 渠道销售额 / 全渠道合计  
- 涨跌% = (本期 − 对比期) / 对比期 × 100（对比期为 0 则空）  
- 完成率% = 实际 / 目标 × 100  
- ROI = 成交 / 花费；费比% = 花费 / 成交 × 100  
- 有日预算无月预算时：月预算 ≈ 日预算 × 当月天数  

## 对用户说明

用简短中文说明输出路径、源文件、空表/占位原因；目标为占位时提示补数字后重跑。
