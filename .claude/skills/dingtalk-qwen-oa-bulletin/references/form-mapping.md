# 行政通报 · processCode 与必填控件映射

供千问办公 Agent 填表对照。对接本企业后务必补全「本企业映射」中的 Schema name。

## 固定配置

```yaml
bulletin:
  formName: 行政通报
  processCode: '' # 必填，例 PROC-XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX
  deptId: '' # 可选，发起部门
  confirmPolicy: always # always | never
```

也可用 `config.local.yaml`（由 `config.example.yaml` 复制）。

## 查找 processCode

```text
列出我可发起的审批表单，找出名称含「行政通报」的，给出 processCode
```

## 必填 11 项（与 SKILL.md 一致）

| 语义（label） | 值类型提示 | 上下文自动填充策略 |
|---------------|------------|-------------------|
| 通报类型 | 单选，value=Schema 枚举 | 话术中的类型/类别；对不上枚举则待确认 |
| 通报责任人 | 人员控件 | @/姓名 → 钉钉通讯录；同名歧义则待确认 |
| 责任人所属部门 | 部门控件 | 由责任人档案反查；查不到再问 |
| 通报关键词 | 文本/多选标签 | 用户给出的关键词；否则从事由提炼并标注 |
| 提议人 | 人员控件 | 默认当前登录用户；用户点名则用点名 |
| 提议积分 | 数字 | 「积 X 分」；无则必问，禁止瞎填 0 |
| 通报事由 | 多行文本 | 事由/经过/说明全文或忠实摘要 |
| 责任类型 | 单选 | 映射 Schema；无法映射则问 |
| 通报分类 | 单选 | 映射 Schema；无法映射则问 |
| 通报数量 | 数字 | 「N 次/件」；无则必问 |
| 奖惩情况 | 文本或选项 | 奖励/处罚描述；无则必问 |

## 排错

| 现象 | 处理 |
|------|------|
| 提示无钉钉工具 | 扩展 → 连接器 → 钉钉登录；新建对话 |
| 搜不到行政通报 | 检查发起权限、模板是否停用 |
| 选项非法 | 使用 Schema 枚举值 |
| 人员/部门填不上 | 先通讯录解析再填；失败则请用户给准确姓名/部门 |
| 无发起类工具 | 按 SKILL.md 产出填表清单，说明需开通或手工提交 |
