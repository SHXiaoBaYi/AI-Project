# 行政通报 OA 审批（千问办公 · 钉钉）

本 Skill 安装到**千问办公**后使用。通过已授权的**钉钉连接器**，完成「行政通报」审批的定位、填表、确认与发起。

## 安装位置

- 目标运行环境：千问办公（QwenWork），技能目录一般为 `~/.qwenworkcn/skills/dingtalk-qwen-oa-bulletin/`
- 安装方式见同目录 [INSTALL.md](INSTALL.md)
- **必须先**在千问办公「扩展 → 连接器」中安装并登录**钉钉**连接器；未连接钉钉时不得假装已发起审批

## 前置检查（每次任务开始）

1. 确认钉钉连接器可用；不可用则引导用户：扩展 → 连接器 → 市场 → 钉钉 → 登录授权，然后**新建对话**再试。
2. 确认企业 OA 存在可发起的「行政通报」模板。
3. 写操作（真正创建审批实例）前必须向用户展示摘要并获得明确确认（用户说「直接发 / 不用确认」时可跳过）。

## 执行流程（严格按序）

```
行政通报审批进度:
- [ ] 1. 解析通报字段（缺必填则追问）
- [ ] 2. 用钉钉连接器定位「行政通报」模板 (processCode)
- [ ] 3. 拉取该模板表单 Schema
- [ ] 4. 按 Schema 组装表单值（禁止臆造选项/控件 id）
- [ ] 5. 如有自选审批人节点 → 流程预测并请用户选定
- [ ] 6. 展示摘要，等待确认
- [ ] 7. 调用连接器创建审批实例，回报 instanceId / 查看路径
```

### 1. 解析字段

从用户话术提取；缺失则追问，**不要编造**：

| 语义 | 用户常说 | 要求 |
|------|---------|------|
| 标题 | 标题、主题 | 建议有；无则用下方默认模板并请确认 |
| 正文 | 内容、事由、说明 | 必填 |
| 类型/级别 | 一般/重要/紧急 | 以表单选项为准 |
| 适用范围 | 全员/某部门 | 按 Schema 填部门或说明 |
| 生效日期 | 今天、某日 | 格式跟 Schema |
| 附件 | 文件 | 无则跳过 |

默认标题（仅建议）：

```text
【行政通报】{摘要≤20字}-{yyyy-MM-dd}
```

### 2. 定位模板

通过钉钉连接器提供的 OA/审批能力：

- 列出当前用户可发起的审批表单，或按关键字搜索「行政通报」「行政通告」
- 优先精确名称「行政通报」；多个命中时列出名称 + processCode 让用户选
- 若 [references/form-mapping.md](references/form-mapping.md) 已填写本企业 `processCode`，直接使用
- 找不到模板：停止，提示检查 OA 后台模板名称与发起权限

对应连接器/工具意图（名称以当前连接器实际工具为准）：

- 列出/搜索可发表单（如 list-forms / search-forms）
- 不要用待办、日历、日志接口代替 OA

### 3. 拉 Schema

在收集完整字段前，用连接器按 `processCode` 获取表单 Schema（如 form-schema）。

映射规则：

- 用控件在 Schema 中的 **id / name** 填值，不要只用中文 label 猜测
- 单选/多选的 value 必须与 Schema 枚举一致
- 对不上的必填控件必须追问用户

### 4. 组装表单值

组装为钉钉 OA 常见的 `formComponentValues` 结构（或连接器要求的等价参数）：

```json
[
  { "name": "控件id或唯一名", "value": "字符串值" }
]
```

明细、附件、部门等复杂控件按 Schema / 连接器文档填写。本企业字段对照表见 `references/form-mapping.md`。

### 5. 流程预测（按需）

若模板含自选审批人/条件分支：先调用流程预测（如 forecast-process），把可选人展示给用户，再写入创建参数中的自选审批人字段。

### 6. 确认摘要

```text
即将发起「行政通报」审批
- 模板: {formName} ({processCode})
- 标题: …
- 正文摘要: …
- 类型/范围/日期: …
- 审批路径: …（如有预测）
请回复「确认发起」或指出要改的字段。
```

### 7. 创建实例

用户确认后，调用钉钉连接器的**创建审批实例**能力（如 create-instance / 发起审批类工具），传入已校验的表单值。

成功后明确回复：

- 实例 ID（instanceId）
- 标题
- 提示：可在钉钉「OA 审批 → 我发起的」中核对

失败时：原样说明连接器/接口错误，对照 Schema 修正后重试；**禁止**静默改字段再发，也禁止在未真正调用成功时声称「已发起」。

若当前企业开通的钉钉连接器**尚未提供发起类工具**（仅有待办/同意/拒绝等）：

1. 仍完成步骤 1–6，生成「可粘贴的填表清单 + 推荐 processCode」
2. 如实告知：连接器暂无法代发，请用户在钉钉 OA 中按清单提交，或联系管理员开通审批发起能力
3. 不得伪造 instanceId

## 对话约定

1. 先复述关键字段，再调连接器写操作。
2. 默认一次只发一张单；批量须用户明确授权，且建议仍逐条确认。
3. 行政通报以 OA 为准，不要用群消息/待办代替正式审批。
4. 不代他人发起（除非连接器与权限明确支持且用户要求）。

## 安全

- 创建/同意/拒绝/撤销均为高影响操作，须确认（见上）。
- 不在回复中输出 access_token、clientSecret 等密钥。
- 附件仅使用用户明确提供的文件。
